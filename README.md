# C语言学习仓库

这个仓库用于记录我的C语言学习过程，包括学习笔记、作业和心得。

## 目录结构

- **学习心得**: 记录在学习过程中的体会和总结
- **作业**: 存储课程作业和练习题  
- **笔记**: 整理的学习笔记和知识点

## 分支说明

- `main`: 主分支，包含项目介绍
- `learning-notes`: 学习心得分支
- `assignments**: 作业分支
- **study-notes**: 笔记分支

## 学习计划

1. 基础语法学习
2. 数据类型和控制结构
3. 函数和指针
4. 文件操作
5. 数据结构和算法
